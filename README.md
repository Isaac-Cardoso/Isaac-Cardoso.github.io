# Isaac Cardoso — Portfolio

A responsive, static personal portfolio built from the content in the supplied resume.

## Publish with GitHub Pages

This project is ready to publish with the included GitHub Actions workflow. Create a GitHub repository for the site, push these files to its `main` branch, then open **Settings → Pages** for that repository and set the source to **GitHub Actions**. The workflow deploys the site after each push to `main`; its first successful run makes the site available at the Pages URL shown in the repository settings.

For the shorter `https://YOUR-USERNAME.github.io/` address, name the repository `YOUR-USERNAME.github.io`. A regular project repository uses a URL like `https://YOUR-USERNAME.github.io/portfolio/`. A custom domain can be connected later in the Pages settings.

## Preview locally

Open `index.html` in a browser. The site uses no build step or runtime dependencies. An internet connection loads the display fonts; system fallbacks are provided.

## Resume source

The embedded preview and download buttons use `assets/Isaac_Cardoso.pdf`. Replace that file to update the resume. The portfolio copy lives in `index.html`, while visual styling is in `styles.css`.
